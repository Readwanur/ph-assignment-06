# 💪 B14-A6-Fit Log

## FitLog: Your No-Nonsense Gym Companion

FitLog is a dark, sleek, and focused workout library and planner. Pick a lift, lock it into today's plan, and watch the week's work add up.

---

###  Key Features
1. **Interactive Workout Library**: Browse an extensive grid of 12 distinct lifts covering all major muscle groups, with stats like duration, calories, and ratings right on the cards.
2. **Dynamic Daily Planner**: Add exercises to "Today's Plan" or save them for later, with real-time updates and toast notifications confirming your actions.
3. **Live Stats Tracking**: Instantly see your total exercises, minutes, and calories for your planned routines calculated in real-time.
4. **Smart Sorting System**: Effortlessly organize your planned or saved workouts by duration, calories, or rating to match your immediate goals.
5. **Mark as Done & Remove Options**: Track your progress by marking completed sets or removing them from your plan with quick, satisfying actions and clear notifications.

###  Technologies Used
- **Next.js (App Router)**: Fast, server-side rendered React applications.
- **Tailwind CSS**: Rapid, utility-first UI styling with responsive design.
- **React Icons**: Scalable SVG icons for a polished look.
- **React Toastify**: Smooth and accessible toast notifications for user actions.
- **Context API**: Efficient state management across the application.

---

###  API Reference
